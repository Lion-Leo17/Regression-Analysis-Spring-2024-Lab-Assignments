# Regression-Analysis-Spring-2024-Lab-Assignments
Jupyter Notebook solutions for the lab assignments of the Regression Analysis course, Spring 2024.

本仓库为 **2024 年春季学期《回归分析》课程上机作业** 的 Jupyter Notebook 代码实现。

本仓库包含五次上机作业的 Jupyter Notebook 代码。

## 如何使用

1. 安装 Jupyter 及常用依赖：

   pip install jupyter numpy pandas matplotlib scikit-learn

2. 在仓库根目录启动 Jupyter：

   jupyter notebook

3. 在浏览器中打开对应的 回归分析1.ipynb ~ 回归分析5.ipynb，按顺序运行即可查看和复现每次作业的代码与结果。
